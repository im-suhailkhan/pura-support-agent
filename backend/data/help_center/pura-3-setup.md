# Pura 3™ — Diffuser Setup

**Product:** Pura 3™
**Topic:** Diffuser Setup

## Setup Video
https://www.youtube.com/watch?v=R_eGz0XNasw

## Step-by-Step Setup Instructions

1. Plug the Pura 3 into a standard wall outlet.
2. Open the Pura app on your phone.
3. Tap "Add Device" and select Pura 3.
4. Follow in-app Wi-Fi connection steps.
5. Insert fragrance vials into both slots.
6. Configure your schedule and intensity in the app.

## Requirements
- 2.4 GHz Wi-Fi network (not 5 GHz)
- Bluetooth enabled during initial pairing
- Pura app (iOS or Android)

## Note
The Pura 3 is a legacy product and is no longer actively sold, but it is fully supported via the Pura app.
