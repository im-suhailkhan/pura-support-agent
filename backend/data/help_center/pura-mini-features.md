# Pura Mini™ — Features

**Product:** Pura Mini™
**Topic:** Features

## Overview
The Pura Mini is designed for small spaces (up to ~300 sq ft) such as bathrooms, entryways, and home offices.

## Key Features
- Single fragrance vial slot
- App-controlled scheduling and intensity
- Adaptive diffusion that adjusts based on ambient temperature
- Compact form factor — fits standard wall outlets without blocking adjacent outlets
- Compatible with all Pura fragrance vials

## Pricing
- Device: $34.99
- Fragrance refills: ~$12–$18 per vial

## Best For
- Bathrooms
- Entryways
- Small offices
- Bedrooms
