# Pura 3™ — Features

**Product:** Pura 3™
**Topic:** Features

## Overview
The Pura 3 is a legacy home diffuser, no longer actively sold but fully supported. It introduced the dual-fragrance system that carries forward into current Pura devices.

## Key Features
- Dual fragrance vial system — use two scents and switch between them on a schedule
- App-controlled scheduling and intensity
- Built-in LED ambient light — color and brightness adjustable in the app
- Compatible with all standard Pura fragrance vials

## Best For
- Medium-sized rooms
- Spaces where ambient LED lighting is desired alongside fragrance
